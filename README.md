# opensesame-cognitive-experiment
OpenSesame experimental task developed for research in clinical neuropsychology, including experimental conditions, counterbalancing and response collection.

## Overview

This repository contains an OpenSesame experimental task associated with a master's thesis in Clinical Neuropsychology at Leiden University.

The experiment includes video-based stimuli, experimental conditions, counterbalancing procedures, participant instructions, practice trials, response collection, and integration with online research tools.

## Software and Experimental Design

- **Software:** OpenSesame 4.1.8
- **Experimental platform:** OpenSesame / OSWeb
- **Online experiment integration:** JATOS
- **Survey integration:** Qualtrics
- **Experimental features:** Counterbalancing, video presentation, practice and experimental trials, and response registration.

## Repository Contents

- `osweb_template.osexp` — A modified version of the OpenSesame experiment prepared for sharing without confidential video URLs or project-specific survey links.

## Data and Stimulus Availability

The original video stimuli and associated URLs are not publicly available due to access restrictions.

For this repository, confidential URLs have been replaced with placeholders. The experiment therefore cannot be run in its original form without authorized stimuli and appropriate configuration.

No participant-level research data are included.

## Research Skills Demonstrated

The experimental task illustrates the use of software and methods relevant to experimental research, including:

- Structuring experimental tasks in OpenSesame.
- Implementing experimental conditions and counterbalancing.
- Presenting video-based stimuli.
- Configuring participant instructions and response collection.
- Integrating experimental tasks with online research platforms.

These features describe the experiment's technical structure and do not necessarily indicate that every component was developed independently by the repository author.

## Purpose of Sharing

This repository documents the technical structure of an experimental research task and supports transparency regarding the research methods and software used.

It is shared to provide insight into experimental task implementation and reproducible research practices.

## Important Note

This repository contains a modified template for documentation purposes, not a fully functional standalone experiment. The original study materials and configurations are not distributed here.
